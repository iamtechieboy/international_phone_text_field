## 0.0.3

- Added automatic light and dark appearance based on the surrounding Flutter theme. Light mode keeps the previous appearance.

- Kept the existing field style, cursor, divider, and decoration parameters. An explicit theme value takes precedence over its matching field parameter.
- Fixed country picker flags to load by country code.
- Updated the README and added widget tests for theme switching and custom values.
